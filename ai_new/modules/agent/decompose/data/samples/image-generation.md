# 文生图

## 用途
根据用户给定的画面描述生成图片；适用于插画、营销配图、产品概念图与海报底图。

## 输入参数
- prompt（string, required）：画面描述，含主体、场景、氛围与风格。
- size（string, optional）：画幅，如 1:1、3:4、16:9，默认 1:1。
- style（string, optional）：风格倾向，如写实、扁平插画、水彩、3D 渲染。
- count（number, optional）：出图张数，默认 1。

## 产出
- 一张或多张图片，返回图片链接或落盘路径；附带所用提示词与参数记录。

## 依赖
- 调用外部图像模型接口；需要接口凭证（环境变量占位）。
- 本地无需额外 Python 包。

## 约束
- 不生成违规、肖像侵权或未授权的人物形象；提示词含敏感指向时先说明并请求确认。
- 出图失败要回显原因，不交付占位图冒充成品。
