## 1. Claude Code + DeepSeek Anthropic 兼容入口

命令：

```powershell
$env:ANTHROPIC_BASE_URL='https://api.deepseek.com/anthropic'
$env:ANTHROPIC_AUTH_TOKEN='sk-...'   # 实际 key 不写入仓库
$env:ANTHROPIC_MODEL='deepseek-chat'
$env:ANTHROPIC_SMALL_FAST_MODEL='deepseek-chat'
claude -p "只回复两个字：正常" --output-format json --permission-mode bypassPermissions
```

结果：

- `is_error: false`
- `result: "正常"`
- `num_turns: 1`
- CLI 输出一条 `[claude-code:unrecognized_model] {"model":"deepseek-chat"...}` 提示；
  请求仍成功，这是 Claude Code 对非 Anthropic 模型名的提示，不是失败。

## 2. 通过 Hive 后端调用外部 Agent

### 2.1 直接后端接口

`POST /api/agents/run`：

```json
{
  "backend": "claude-code",
  "prompt": "在当前工作目录创建 hello.txt，内容为 OK；然后用一句话说明你做了什么。",
  "workspace": "<temp>/probe",
  "system_prompt": "你是执行型 agent，直接动手，不要只解释。"
}
```

结果：`status=ok`，`probe/hello.txt` 存在且内容为 `OK`。

### 2.2 通过 Sessions 选择后端

```json
{
  "kind": "manual",
  "role": "probe",
  "backend": "claude-code",
  "input": "在当前工作目录创建 session.txt，内容为 SESSION；然后一句话汇报。"
}
```

结果：

- `sessions.get` 返回 `backend=claude-code`；
- `sessions.wait` 返回 `status=ok`；
- 会话 workspace 内 `session.txt` 存在且内容为 `SESSION`；
- 说明 `Sessions -> BackendRegistry -> ClaudeCodeBackend` 的选择链真实生效，
  不是绕过会话直接跑 CLI。
